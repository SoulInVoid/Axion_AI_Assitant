🤖 Axion — AI Assistant

Your personal desktop assistant, built with Python.

Axion is a desktop voice assistant designed to make everyday computer interactions easier through simple voice commands. It can perform basic tasks such as opening applications, closing things, and going to sleep.

🚧 Status: Beta — Axion is currently under development. More features, improvements, and updates are on the way!

✨ Features
🎙️ Voice Assistant — Interact with your PC using voice commands.
🚀 Open Applications — Open supported applications and items using commands.
❌ Close Applications — Close supported applications and tasks.
😴 Sleep Mode — Put the assistant to sleep when it's not needed.
🖥️ Desktop Support — Currently designed for PCs.
🔄 Continuous Development — Regular improvements and new features are planned.

Note: Features and command support may vary during the beta phase.
